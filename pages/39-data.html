Deux API, prêtes à intégrer

Legal Data API

Intégrez des sources juridiques officielles à votre logiciel, sans construire votre propre infrastructure de collecte.

Pour les legaltechs, la RegTech, les copilotes juridiques et les logiciels de conformité.

Vous envoyez

  • un pays
  • une source
  • une recherche juridique
  • un identifiant de document, si vous l'avez

Cleo renvoie

  • les textes et décisions disponibles
  • leurs métadonnées
  • le texte intégral, lorsqu'il est ingéré
  • la juridiction, la source et l'autorité
  • le lien vers la source officielle, lorsqu'il existe

Customs Classification API

Transformez une description produit en codes douaniers candidats, prêts à être vérifiés et intégrés à votre workflow.

Pour l'e-commerce cross-border, les ERP, les TMS, les logiciels import-export et les courtiers.

Vous envoyez

  • une description produit
  • le pays ou le système douanier recherché
  • des caractéristiques produit, si vous les avez

Cleo renvoie

  • des codes douaniers candidats
  • leur niveau de confiance
  • la nomenclature utilisée
  • la provenance de la donnée
  • selon le pays, les droits et le coût rendu (landed cost), par des appels complémentaires

Questions fréquentes

Quelle API choisir ?
Legal Data API si votre logiciel cherche, lit ou cite des textes juridiques. Customs Classification API si votre logiciel doit proposer un code douanier à partir d'une description produit.
Les codes douaniers renvoyés sont-ils définitifs ?
Ce sont des codes candidats. Chacun arrive avec son niveau de confiance, la nomenclature utilisée et la provenance de la donnée, pour que votre équipe ou votre courtier le vérifie avant la déclaration.
D'où viennent les textes de Legal Data API ?
Des sources juridiques officielles de chaque pays. Chaque document indique sa juridiction, sa source et son autorité, avec le lien vers la source officielle lorsqu'il existe. Explorez les pays et les sources.
Peut-on utiliser Legal Data dans un assistant IA ?
Oui, avec le serveur MCP : dans Claude, Cursor et tout client compatible MCP.
Combien coûte l'accès ?
Le prix dépend de votre usage : les pays, les sources et le volume d'appels. Décrivez votre usage, l'équipe vous répond.
Quand arrivent Product Scope et Marketplace Gate ?
Pour les utiliser en premier, devenez design partner : écrivez à l'équipe avec votre cas d'usage.
