Customs Classification API

Une description produit devient des codes douaniers candidats, expliqués, pour pré-classer votre catalogue et isoler les cas à faire valider.

GET /v2/customs/lookup

GET /v2/customs/lookup?description=cotton+t-shirt&system=cn8&top=5
Host: api.legaldata.cleolabs.co
Authorization: Bearer $CLEO_API_KEY
Vous envoyez
une description produit, puis le pays, la langue et la nomenclature
Cleo renvoie
des candidats avec code, nomenclature, chapitre, niveau de confiance, justification et indicateur d'ambiguïté
Pour
e-commerce, marketplaces, PIM, PLM, ERP, équipes import-export et commissionnaires
  • Nomenclatures servies : HS6, NC8 de l'Union européenne, TN VED du Kazakhstan
  • Pays couverts annoncés avant le contrat
  • Des candidats à faire valider, jamais un classement opposable

Questions fréquentes

Quelle API choisir ?
Legal Data API si votre logiciel cherche, lit ou cite des documents juridiques. Customs Classification API si votre logiciel doit proposer un code douanier à partir d'une description produit.
Les codes douaniers renvoyés sont-ils définitifs ?
Ce sont des candidats expliqués, avec leur niveau de confiance et un indicateur d'ambiguïté. Votre équipe ou votre commissionnaire valide le code avant la déclaration.
D'où viennent les documents de Legal Data API ?
Chaque document indique sa source et l'URL du portail d'origine. Les sources incluses dans votre accès sont nommées dans votre contrat. Explorez la couverture.
Combien coûte l'accès ?
Sandbox gratuit pour tester, Starter à 100 € par mois, Pro à 349 € par mois, Enterprise sur devis. Voir les tarifs.
Peut-on utiliser Legal Data dans un assistant IA ?
Oui, avec le serveur MCP, la même clé que l'API.
Quand arrivent Product Scope et Marketplace Gate ?
Pour les utiliser en premier, devenez design partner : écrivez à l'équipe avec votre cas d'usage.
