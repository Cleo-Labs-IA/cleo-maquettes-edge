Legal Data API

Bring official legal sources into your software, without building your own collection infrastructure.

For legaltechs, RegTech, legal copilots and compliance software.

You send

  • a country
  • a source
  • a legal search
  • a document ID, if you have one

Cleo returns

  • the available texts and decisions
  • their metadata
  • the full text, when ingested
  • the jurisdiction, source and authority
  • the link to the official source, when available
See the API documentationExplore countries and sources

Also in Claude, Cursor and any MCP-compatible client, with the MCP server.

Customs Classification API

Turn a product description into candidate customs codes, ready to be checked and built into your workflow.

For cross-border e-commerce, ERPs, TMSs, import-export software and brokers.

You send

  • a product description
  • the country or customs system you need
  • product characteristics, if you have them

Cleo returns

  • candidate customs codes
  • their confidence level
  • the nomenclature used
  • the data provenance
  • depending on the country, duties and landed cost, through additional endpoints

Frequently asked questions

Which API should I choose?
Legal Data API if your software searches, reads or cites legal texts. Customs Classification API if your software needs to suggest a customs code from a product description.
Are the customs codes final?
They are candidate codes. Each one comes with its confidence level, the nomenclature used and the data provenance, so your team or your broker can check it before the declaration.
Where do the Legal Data API texts come from?
From official legal sources in each country. Each document states its jurisdiction, source and authority, with the link to the official source when available. Explore countries and sources.
Can I use Legal Data in an AI assistant?
Yes, with the MCP server: in Claude, Cursor and any MCP-compatible client.
How much does access cost?
The price depends on your usage: countries, sources and call volume. Describe your usage and the team will get back to you.
