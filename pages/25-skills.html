FAQ

Questions fréquentes

Qu'est-ce que le Skills Library ?
Une collection gratuite et open source de 45 skills de conformité produit exposés via un serveur Model Context Protocol (MCP). Tout agent IA compatible (Claude Code, Cursor, ChatGPT desktop ou le vôtre) peut les appeler pour répondre à des questions réglementaires en cosmétique, alimentaire, électronique, jouets, textile et compléments.
Comment l'installer ?
Une commande : npx -y @cleo-labs/skills-mcp@latest. Ajoutez-la à la configuration de votre client MCP (Claude Code, Cursor, etc.) et les 45 skills sont disponibles immédiatement.
C'est vraiment gratuit ?
Oui. Licence MIT. Utilisez-le dans des produits commerciaux, reprenez-le, modifiez-le. Nous le maintenons parce que nous l'utilisons nous-mêmes chez Cleo.
Quelle est la différence avec Cleo ?
Les skills donnent le « quoi » : la connaissance des réglementations, référentiels et certifications. Cleo donne le « comment » : votre catalogue rapproché des règles de 106 pays, suivi en continu, avec les preuves pour l'audit et le travail d'équipe.
Quels clients MCP sont supportés ?
Tout ce qui parle MCP via stdio. Testé avec Claude Code, Claude Desktop, Cursor et Continue. Le serveur est une surcouche légère : s'adapter à un nouveau client est principalement une question de configuration.
