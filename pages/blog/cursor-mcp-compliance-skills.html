1. Pourquoi ça compte

Quand nous avons open-sourcé la skills_library il y a quelques jours, le feedback le plus fréquent était : « j’adore Cursor, est-ce que je peux l’utiliser sans quitter mon éditeur ? ». La réponse est oui, et depuis cette semaine, l’expérience est identique à celle de Claude Code. Mêmes 45 skills, même pont vers la Cleo Legal API, même licence MIT. Seule la fenêtre où vous tapez le prompt change.

Si vous développez une app Shopify, une intégration marketplace, un tunnel de paiement ou un générateur d’étiquettes et que vous avez besoin de réponses conformité réelles (seuils REACH, périmètre CE, flux de notification JIS) sans switcher vers un consultant ou un cabinet à 5 K€ : c’est le chemin le plus court que nous connaissions.

2. L’installation en une ligne

Cursor lit ses serveurs MCP depuis un seul fichier JSON. Ouvrez Cursor → Settings → MCP, cliquez sur « Add new MCP server » et collez ceci :

{ "mcpServers": { "cleo-skills": { "command": "npx", "args": ["-y", "@cleo-labs/skills-mcp@latest"] } } }

Sauvegardez le fichier. Cursor relance l’hôte MCP automatiquement. Le premier lancement télécharge le package (~4 Mo) depuis npm, enregistre les 45 skills, et vous êtes en ligne. Pas besoin de clé API pour le catalogue de base : les skills fonctionnent en autonome via la connaissance de Claude et WebSearch.

Le package est ici : npmjs.com/package/@cleo-labs/skills-mcp. Source sur GitHub : github.com/Cleo-Labs-IA/skills_library.

3. Trois requêtes à tester dans les 60 prochaines secondes

Ouvrez la composer de Cursor (Cmd-K ou Cmd-I), passez en mode Agent et essayez ces trois prompts. Chacun appelle un skill différent pour vous montrer l’éventail.

Requête 1 : check substance

« L’hexylresorcinol est-il autorisé dans un sérum visage vendu en France à 0,5 % ? »

Ce que vous voyez dans Cursor

L’agent appelle le skill product-compliance, renvoie un verdict en environ 9 secondes : l’hexylresorcinol n’est ni en Annexe II (interdit) ni en Annexe III (restreint) du règlement 1223/2009, donc autorisé en leave-on à la discrétion du formulateur sous réserve du dossier sécurité. Le skill cite l’entrée CosIng 56-43-9 et suggère un check CMR via ECHA. Vous voyez aussi la trace de raisonnement : utile quand vous collez la réponse dans une description de PR.

Requête 2 : générateur d’étiquette

« Génère les mentions obligatoires du dos de l’étiquette d’un shampoing 50 ml vendu en Allemagne, Espagne et Italie. »

Ce que vous voyez dans Cursor

Le skill labeling-compliance renvoie le template INCI complet, le format du numéro de lot, la règle du symbole PAO (12M classique pour les shampoings), le contenu nominal en métrique, le bloc Personne Responsable et les trois exigences linguistiques (DE, ES, IT). Temps total : environ 11 secondes. L’agent propose de coller le résultat directement dans votre fichier product.tsx sous forme de constante. C’est précisément ce détail qui a fait demander Cursor par la communauté.

Requête 3 : scan multi-marchés

« Puis-je vendre une lampe de bureau LED 12V dans l’UE, au UK, aux US et au Canada ? Liste les certifications. »

Ce que vous voyez dans Cursor

Le skill multi-jurisdiction-scan lance quatre vérifications en parallèle. Environ 18 secondes plus tard : UE = marquage CE (LVD 2014/35/UE, CEM 2014/30/UE, RoHS 3, ErP), UK = UKCA, US = FCC Part 15 + UL safety listing, Canada = ISED + CSA / cULus. Le résultat arrive sous forme de tableau à quatre colonnes que vous collez dans votre ticket ingénierie. Le budget tests cumulé (~4 à 7 K€) est inclus en note de bas de page.

4. Pourquoi c’est important pour les fondateurs D2C

Un fondateur qui code dans Cursor aujourd’hui est probablement aussi celui qui écrit le copy marketing, les flows Klaviyo, les extensions de checkout Shopify et qui review le legal à 23 h. Le coût du context-switching est réel. À chaque fois que vous quittez votre éditeur pour poser une question à 30 secondes à un consultant, vous perdez 20 minutes de flow.

Cleo Skills dans Cursor compriment cette boucle. Les skills tournent là où vous codez. La réponse atterrit dans le fichier. La citation est dans le commentaire. Votre reviewer (ou votre vous dans trois mois) lit la réglementation à côté du code.

Et puisque la Cleo Legal API (en option) peut être branchée en complément des skills via MCP, vous obtenez les données live quand vous en avez besoin (limites de substances mises à jour chaque semaine, taux de douane chaque jour) sans rien rebuilder.

5. Dépannage (les trois seuls trucs qui plantent)

  • Version Node : le serveur MCP requiert Node 18+. Si npx échoue silencieusement, lancez « node -v » et upgradez via nvm. Cursor n’embarque pas Node.
  • Cache obsolète : si un skill renvoie « not found » au premier appel, lancez une fois « npx -y @cleo-labs/skills-mcp@latest --refresh » et relancez Cursor.
  • Proxy d’entreprise : si vous êtes derrière un proxy, définissez HTTPS_PROXY avant de lancer Cursor. Le package est du npm classique : mêmes règles.

Questions fréquentes

Faut-il une clé API pour utiliser les skills dans Cursor ?
Non. Les 45 skills fonctionnent en autonome via la connaissance interne de Claude et WebSearch. La Cleo Legal API (optionnelle) n'ajoute que les données en temps réel : seuils de substances mis à jour chaque semaine, taux de douane chaque jour. Un free tier existe si vous voulez essayer.
Ça marche dans Cline, Windsurf ou d'autres hôtes MCP ?
Oui. Le package npm @cleo-labs/skills-mcp implémente le protocole MCP standard : n'importe quel hôte MCP peut le lancer. Le snippet JSON de l'article fonctionne à l'identique dans Cline, Windsurf, Continue et Claude Desktop.
Quelle version de Node est requise ?
Node 18 ou supérieur. Cursor n'embarque pas Node, donc installez-le globalement via nvm ou votre gestionnaire de packages avant de configurer le serveur MCP. Lancez « node -v » pour vérifier avant le premier appel npx.
Est-ce vraiment gratuit ?
Oui. La skills_library est sous licence MIT sur GitHub. Le package npm est gratuit à installer. Pas de télémétrie, pas d'inscription, pas de plafond d'usage sur le catalogue de base. La Cleo Legal API a des paliers payants mais ils sont optionnels et ne s'activent que pour les données en temps réel.
